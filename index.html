SOLUTIONS

產品與解決方案矩陣

從單一展品 PoC，到整館旗艦場域，再到跨城市的分散式全像節點，H.A.I 以模組化方式提供硬體、內容與 平台服務，讓博物館、美術館、品牌與城市公共藝術都能快速導入。

1. Museum-in-a-Box – 可攜式互動展品

針對教育場域、行動巡迴展與企業展示，提供「一箱到位」的全像互動裝置：內含 Edge AI 模組、LCoS 顯示、 定向揚聲器與預載內容，支援離線與雲端同步兩種模式。

學校巡迴展 企業品牌館 快閃活動 / Pop-up

2. Flagship Holo Gallery – 旗艦級沉浸式展廳

為美術館與大型場館打造多節點全像裝置，支援多幅名畫、多件雕塑與沉浸式故事線，搭配策展人後台系統 進行情境編排與數據分析。

可編排式情境腳本 觀眾行為熱力圖 A/B 測試不同版本故事

3. H.A.I Cloud & Edge Platform – 平台與 API

以 PaaS 形式提供裝置管理、模型更新、內容發佈與數據分析後台，讓國際合作策展與 IP 方可以遠端上架 新作品，並即時查看各場域的互動指標。

多場域裝置管理 聯邦學習模型更新 內容授權與計費 API

4. Consulting & Co-Creation – 聯合策展與顧問服務

與博物館、設計團隊與藝術家共同開發新型態作品，從技術可行性評估、體驗設計到營運模式設計，形成 長期合作的「內容生態系」。

IP 授權合作 全像內容共創 長期維運合約

BUSINESS MODEL

營運模式與收入結構

透過「裝置銷售 + SaaS / PaaS 授權 + 內容分潤」，H.A.I 形成兼具一次性與經常性收入的商業模式， 同時保留與 IP 方及場館長期共創的彈性。

收入來源

  • 硬體裝置與整合專案收入
  • 平台訂閱 / SaaS 授權 (月費 / 年費)
  • 內容授權與票房分潤
  • 技術顧問與聯合策展服務

早期以旗艦示範場域與 PoC 專案為主，中期導入多場域平台化部署，長期打造跨城市、跨國家的 H.A.I 全像節點網路。

營運辦法與合作模式（示意）

  • 與場館簽訂 3–5 年長期合作合約
  • 由 H.A.I 提供硬體、平台與維運服務
  • 策展方 / IP 方提供內容與故事線
  • 雙方依票房、導覽收入或授權費分潤

可視場域規模與資本結構調整 CAPEX / OPEX 比例，例如採用收入分享、租賃或 PPP / BOT 等模式， 降低場館一次性投資壓力。

FOR INVESTORS

投資人專區：2 分鐘重點總結

本區可對應簡報與 PDF 投資提案，快速說明市場痛點、技術護城河與財務成長路徑，方便評審與 投資人在有限時間內掌握精華。

一、我們解決的痛點

  • 現有展場多為單向播片，缺乏人味與記憶點。
  • VR / AR 需要頭盔，破壞公共場域的社交感與儀式感。
  • 純雲端串流延遲與頻寬昂貴，不適合大量即時互動。

二、Holo-Artisan 的解法

  • 多用戶、無穿戴、即時個人化全像顯示。
  • Edge AI + 聯邦學習：端到端延遲 < 35 ms，頻寬節省 > 99%。
  • 從硬體系統 → 內容平台 → SaaS / PaaS 生態系。
